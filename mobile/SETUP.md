# הגדרה חד-פעמית: הוספה מהירה מהנייד

## 1. Google Cloud Console (כ-15 דקות, פעם אחת)

1. היכנסו ל-[console.cloud.google.com](https://console.cloud.google.com) וצרו פרויקט חדש (או השתמשו בקיים).
2. **APIs & Services → Library** → חפשו "Google Drive API" → **Enable**.
3. **APIs & Services → OAuth consent screen**:
   - User type: **External**.
   - מלאו שם אפליקציה (לדוגמה "ניהול כספים - הוספה מהירה") ואימייל תמיכה (האימייל שלכם).
   - בשלב ה-Scopes אין צורך להוסיף כלום ידנית.
   - בשלב Test users: הוסיפו את חשבון ה-Gmail שלכם.
   - אפשר להשאיר את האפליקציה במצב **Testing** לצמיתות - לא נדרש אימות גוגל כי ה-scope המבוקש (`drive.file`) אינו רגיש.
4. **APIs & Services → Credentials → Create Credentials → OAuth client ID**:
   - Application type: **Web application**.
   - **Authorized JavaScript origins**: הכתובת האמיתית שבה תארחו את `mobile/` (לדוגמה `https://your-domain.com` או, לבדיקות, `http://localhost:8799`). **חייב** להיות `https://` או `http://localhost` - לא יעבוד מ-`file://`.
   - שמרו - תקבלו **Client ID** שנראה כך: `xxxxxxxxxxxx.apps.googleusercontent.com`.
5. **APIs & Services → Credentials → Create Credentials → API key**:
   - זה נדרש עבור חלון הבחירה של קבצים ב-Drive (Picker) - מתברר ש-scope מסוג `drive.file` לא מספיק בשביל לגשת לקובץ רק לפי מזהה/קישור שהודבק; צריך לבחור את הקובץ פיזית דרך חלון הבחירה של Google בפעם הראשונה.
   - אפשר (לא חובה) להגביל את המפתח ל-"Google Picker API" ול-HTTP referrer של הכתובת שלכם, לאבטחה נוספת.
   - העתיקו את ה-**API Key** שנוצר.

## 2. בחירת קובץ הנתונים ב-Drive

אין צורך להעתיק קישור מראש - זה קורה בתוך האפליקציה עצמה (ראו שלב 4): בלחיצה על "התחבר ובחר קובץ" ייפתח חלון בחירה אמיתי של Google Drive, ושם תבחרו את `personal-finance.json`. זו הדרך הנכונה (ולמעשה היחידה) לתת לאפליקציה גישה לקובץ ספציפי שלא נוצר על ידה.

## 3. אירוח (Hosting)

ה-PWA חייב לרוץ מכתובת `https://` אמיתית (או `http://localhost` לבדיקות) - לא ניתן לפתוח אותו כקובץ מקומי (`file://`) כי גם ה-Service Worker וגם ההתחברות ל-Google לא עובדים משם.
אפשרויות פשוטות: GitHub Pages, Netlify/Vercel (גרירת תיקייה), או כל שרת סטטי זול אחר. ודאו שהכתובת תואמת בדיוק למה שרשמתם ב-"Authorized JavaScript origins" למעלה.

## 4. הגדרה באפליקציה עצמה

1. פתחו את `https://<הכתובת-שלכם>/mobile/index.html`.
2. הדביקו את ה-**Client ID** ואת ה-**API Key**.
3. לחצו "התחבר ובחר קובץ" - תתבקשו להתחבר לחשבון הגוגל שלכם ולאשר גישה, ואז ייפתח חלון בחירה של Drive - בחרו את `personal-finance.json`.

## 5. התקנה בנייד כאפליקציה

1. פתחו את הכתובת ב-Chrome באנדרואיד.
2. תפריט (⋮) → **הוספה למסך הבית** / **התקן אפליקציה**.
3. מעתה תוכלו לפתוח אותה כאפליקציה עצמאית, גם ללא חיבור לאינטרנט.

## שימוש שוטף

- מילוי הטופס ולחיצה על "שמור" שומר תמיד קודם **מקומית** במכשיר, גם בלי אינטרנט.
- כשיש חיבור, האפליקציה מנסה לסנכרן אוטומטית; אפשר גם ללחוץ "סנכרן עכשיו" ידנית.
- אחרי כשעה ההתחברות פגה ודורשת הקשה ידנית על "סנכרן עכשיו" (מגבלה של גוגל - אין רענון שקט ברקע).
- "שינוי חיבור ל-Drive" מאפס את ההגדרה (שימושי אם צריך לחבר קובץ אחר).
